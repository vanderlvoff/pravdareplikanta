# Типографика статей

По обновлённому выбору владельца текст статей и заголовки в вебе и PDF используют
тот же набор гарнитур, что и футер: `Arial, sans-serif`. Обычный текст — Regular,
заголовки — Bold. Основной текст PDF остаётся 10pt, заголовки — 16pt.

Для японских символов браузер выбирает системный японский sans-serif: Arial
не содержит японских иероглифов. Футер и статьи используют одинаковый стек;
на другой операционной системе конкретный японский шрифт может отличаться.
PDF сохраняет используемые шрифты/глифы внутри файла, и их встраивание проверяется.

Девизы сохраняют свои локальные шрифты: Caveat для RU/EN и Zen Kurenaido для JA.
Утверждённые SVG, портрет, ордена и их пропорции не меняются.

PT Serif и Noto Serif JP остаются в `assets/fonts/` как сохранённые варианты
предыдущей примерки. Их font-face объявления удалены, файлы не копируются в
новые снимки сайта и не загружаются читателем. Старые снимки с этими шрифтами
остаются доступны для сравнения.

## Сохранённые варианты с засечками

PT Serif взят без изменения бинарных файлов из Google Fonts, commit
`6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec`, версия `1.000W OFL`.
Noto Serif JP взят из того же закреплённого Google Fonts commit, версия
`2.003-H1`. Лицензии SIL OFL 1.1 сохранены рядом со шрифтами; эти варианты сейчас не копируются в сборку.
Точные URL, хеши и сведения о происхождении приведены в README каталогов
`assets/fonts/PTSerif/` и `assets/fonts/NotoSerifJP/`.

У Noto сохранён исходный variable TrueType. Из него воспроизводимо подготовлены
статические экземпляры Regular/Bold с помощью FontTools 4.60.1; они сохранены
для сравнения, но не используются в текущих веб/PDF-сборках. Это фиксирует веса и позволяет проверять именованное встраивание
шрифтов в PDF закреплённым Chromium. Исходный файл не заменяется.

Для обычной сборки FontTools не нужен: готовые TTF уже находятся в репозитории.
Повторная подготовка статических экземпляров при необходимости:

```sh
python -m pip install -e '.[fonts]'
python scripts/prepare_article_fonts.py --update-manifest
```

Команда работает без сети, проверяет хеш исходного шрифта, фиксирует веса 400/700,
сохраняет исходную временную метку и обновляет только записи двух подготовленных
TTF в `assets/MANIFEST.json`. Все файлы остаются под OFL 1.1.

## Проверки

- Chromium дожидается готовности шрифтов до измерения колонок.
- Проверяется, что гарнитура текста/заголовков совпадает со стеком футера, а
  шрифты девизов остаются прежними. Фактически используемые гарнитуры записываются
  через Chromium Font Inspection.
- PDF проверяется на встраивание используемых шрифтов, полноту текста и переполнения.
- Растровые PDF-страницы и мобильные веб-страницы просматриваются после смены гарнитур.
- Старые снимки с локальными шрифтами статей сохраняют проверку встраивания
  PT Serif/Noto Serif JP; новое оформление не меняет старые артефакты.

Пагинация рассчитывается заново по метрикам шрифтов. Число страниц может меняться;
размеры текста не уменьшаются ради подгонки.
